# Archived run scripts

Run scripts for experiments that were dropped (3-B, `22`–`29`) or that died (rule-based 3-C / YARA, `34`–`37`). See
`docs/graveyard.md` for why. Their scripts are in `scripts/archive/`; their artifacts remain under
`artifacts/experiments/`. The paths inside these scripts (`scripts/...`) are as they were before archiving and are
not kept in sync; they document what was run, not a command to re-run.
