\section*{How to read this}

\textbf{Option 1 (recommended): one table per finding.} Table~\ref{tab:hand} (5.2, replaces Table 3),
Table~\ref{tab:observed} (5.3, new), Table~\ref{tab:cost} (5.4, replaces Table 4), and Table~\ref{tab:ops} (5.4, new;
takes the numbers out of the paragraph \emph{Where the cost lies}).

\textbf{Option 2: one detectors table.} Table~\ref{tab:all} replaces Tables~\ref{tab:observed} and~\ref{tab:cost}; 5.2,
5.3 and 5.4 all point to it. Tables~\ref{tab:hand} and~\ref{tab:ops} stay as in option 1.

All numbers are the current ones; the cells new to the paper (TPR at 0.1\% FPR and AUC for PV, ERDALT and adversarial
training) were computed from the stored test predictions in the same way as Table 4's.
